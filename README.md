# cloverboyz

A Roblox game. Rojo project with the ProfileStore + Replica data stack and
Blink networking.

## Working on it

```
rokit install                 # rojo, wally, lune, stylua, blink, tungsten at the pinned versions
wally install                 # packages into Packages/
blink src/network --watch     # recompiles src/shared/Network when the schema changes
rojo serve                    # then connect from the Rojo plugin in Studio
```

Checks, all runnable without Studio:

```
rojo build -o build.rbxl          # the project tree assembles
blink src/network                 # the schema compiles
stylua --check src                # formatting
python3 tools/check_schema.py     # every profile write lands on a field the template declares
```

## Layout

```
src/
  network.blink    every remote in the game; compiled by Blink, never synced itself
  shared/          ReplicatedStorage.Shared — Loader, Global helpers, Game_Settings
    Network/       GENERATED by Blink: Server, Client, Types
    Assets/        GENERATED by Tungsten: asset ids
  server/          ServerScriptService.Server — Data service + every server module
  client/          StarterPlayerScripts.Client — Data view + every client module
  replicatedfirst/
assets/ui/         images Tungsten uploads
tools/             scripts that run outside Studio
Packages/          wally output (gitignored)
```

Any ModuleScript dropped into `src/server` or `src/client` is booted by
`Shared/Loader` automatically. Return a table with optional `OnInit(self)` and
`OnStart(self)` to hook the lifecycle.

## Networking

Remotes are declared in `src/network.blink` and compiled into
`src/shared/Network/`. Edit the schema, never the output; the output is
committed so the project builds without running Blink.

Blink validates the shape and bounds of everything a client sends before a
handler runs. It does not limit how often. Every client-initiated handler
starts with a `server/RateLimit` check, with its rate in `Game_Settings.Network`:

```luau
local limiter = RateLimit.new(perSecond, burst)

Net.Something.On(function(player, value)
    if not limiter:Allow(player) then
        return
    end
    -- ...
end)
```

Two examples ship: `Notify` (server to client, see `server/Notifications` and
`client/Notifications`) and `GetServerTime` (client to server, rate-limited,
see `server/Clock`).

## Assets

Drop images in `assets/ui/` and run `tungsten sync cloud`. Tungsten uploads
what is new, writes the ids to `src/shared/Assets/UI.luau`, and records what
is up in `tungsten.lock.toml` (commit it). The Open Cloud key goes in `.env`
as `TUNGSTEN_API_KEY`; the creator it uploads under is in `tungsten.toml`.
